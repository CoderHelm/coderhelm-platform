# ox. `ox_findings_raised_first`

**What happened:** On the same pull request as `ow`, a review three rounds in raised "A parallel structure next to an existing one" and "A test out of proportion to the change" on code unchanged since the first review, and said they should have been raised then. On CoderHelm's own pull request each late note was still work that held the merge, so each cost a push and a review. The checks that find them started running after the earlier rounds were reviewed. Three more ways a first review left findings for later were open: the checks with no model ran only when the head's tree could be read, a diff over its room lost the files in its middle, and a review that ran out of tool steps answered as if it were done.

**The guarantee:** Every check runs on every review, the first included, with or without the tree. The reviewer's diff names every changed file and lists the ones it cut. A review that runs out of steps goes on in a second pass over what it didn't reach. A finding a later review raises on lines unchanged since the previous one never blocks: it is a note saying the previous review missed it, or that the check that found it started after it. On CoderHelm's own pull request it is still sent to the coder in this round's work. A miss is recorded for the reviewer's rewards and lessons; a new check's finding is not.

**Where it's enforced:** `review_policy::hold_late_blockers` (`Late::missed`, `NEW_CHECK_NOTE`), `review_rules::CHECKS_STARTED`, `rewards::record_missed` and `RewardKind::FindingMissed`, `review_agent::format_diff`, `review_agent::generate_review` (`ran_out_of_steps`, `continue_prompt`, `merge_review`), and the checks block in `review_pr`.
