# ca. `ca_related_ticket_covered`

**What happened:** A ticket's pull request was closed by a person who expected a linked ticket's pull request to cover it. The pull request that was kept never read the linked ticket: when it was called ready, the drawer's Register button still pointed to the old address.

**The guarantee:** The Jira app sends the ticket's issue links and the tickets its text names, with their summaries and descriptions. The gateway keeps them on the run's message, the planner reads their acceptance criteria as part of the change, and the run keeps them. Before the pull request is called ready, each address a pull request closed in favor of this one moved is checked on the head's files, each link criterion is checked on the preview page, and anything else is listed as not covered with why, in the description's "Related tickets" section.
