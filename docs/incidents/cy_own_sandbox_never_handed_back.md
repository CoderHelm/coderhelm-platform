# cy. `cy_own_sandbox_never_handed_back`

**What happened:** A run to fix a flaky end-to-end test never ran the test. Its repeat runs on the base branch failed before any test started, because the sandbox couldn't download Chromium. Playwright's CDN redirects the browser build to a shared storage host that wasn't on the network allowlist, and the `--with-deps` install failed first on the OS package mirrors, with its error hidden. Those runs were still counted, so 0 of 480 passed and the test was called "not flaky, failing every run". CoderHelm's own review then asked for 20 repeat runs. Against the team's staging site and against the pull request's preview, all 20 of 20 failed with `net::ERR_TUNNEL_CONNECTION_FAILED`, and the proxy printed `CODERHELM_EGRESS_BLOCKED` for both hosts. At the same time, `check_url` could read both pages. The round ended "NEEDS A PERSON ... outside_reach: add the hosts to CoderHelm's sandbox network allowlist", and the pull request stayed held. In the same two weeks, eleven more runs on that install hit the same sandbox problems.

**The guarantee:** The sandbox can reach the team's own hosts, taken from its settings: the domains `check_url` reads, plus its saved test and preview addresses. It can also reach the hosts CoderHelm's own tooling needs, whatever list the team saved. Playwright's browsers come through the proxy's own mirror, which follows a redirect only into the browser builds' folder on the shared host, and the browsers are kept on the build host between builds. A browser install falls back to the browser alone when the OS package step can't run. Tests that never started are never counted as failures. A round blocked by CoderHelm's own environment is a block that the next round removes, never a person's step. That next round runs again, and if the sandbox still can't, it reads the repository's CI on the branch or uses the evidence it can get. The person gate treats "add hosts to CoderHelm's allowlist" as CoderHelm's own work. Once the environment has blocked a proof twice, the review judges the evidence the rounds could get.

**Where it's enforced:** `agent_policy::sandbox::{run_allowlist, own_hosts, TOOLING_HOSTS}` and `agent::policy::sandbox_egress`. The Playwright mirror is in `egress_proxy.py`, and `PLAYWRIGHT_DOWNLOAD_HOST` and the browser cache are set in the sandbox buildspec (`infra/lib/worker-stack.ts`). Also: `e2e::test_package::BROWSER_INSTALL`, `stop_rules::tooling::{runner_never_started, names_own_tooling}`, `test_bug::counts_of`, `own_review_ledger::Blocker::Tooling` (with `blockers_of`, `observe`, `instruction` and `round_rules`), `person_gate::decide`, and `review_discipline::unobtainable`.
