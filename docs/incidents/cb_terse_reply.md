# cb. `cb_terse_reply`

**What happened:** A person wrote "@CoderHelm rebase with main" on a pull request. CoderHelm merged main in, since force pushes were off, and replied with a quote of that very comment, an "@name, replying to your comment" header linking it, a second @-mention of the person, "you asked for a rebase with main:", two clauses on how the merge was done, and "It's pushed to pull request #N", a link to the pull request the reply sat on. The owner objected to how long and noisy it was.

**The guarantee:** A branch update answers in one line, the outcome first ("Merged main in (7c0ffee)."), with one short reason only when it is a merge where a rebase was asked. That line is posted as written; no model rewrites it. Every comment CoderHelm posts passes the thread rules (`comment_style::tidy` and `comment_style::lint_on`): under the newest comment a reply has no quote, no header and no name; under an older comment it has a quote only; a person is @-mentioned once at most; it never links the thread it is posted on; it never says the request back.
