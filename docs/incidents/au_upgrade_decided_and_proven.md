# au. `au_upgrade_decided_and_proven`

**What happened:** An outside reviewer checked a dependency security pull request of dozens of packages, several across a major version. The code was sound and the account of it was not: its count of advisories left was CoderHelm's own and disagreed with the package manager's production audit of the same head; one package of a framework was raised while its siblings from the same source repository stayed behind; no type check was recorded, because the repository's CI has none and CoderHelm's checks mirrored CI; it said "contract unchanged" although a validation library's major changed the 400 error bodies of an endpoint; and each override across a major lacked why it is safe.

**The guarantee:** A dependency update is decided and proven by the pipeline (`common::upgrade_quality`). Packages released together are found from the registry's source repository and the base branch's lockfile, move as one bump, and a lockfile that splits them fails the set like any check. The set a dependency change is verified with (frozen install with the manifest's package manager version and the deployment image's, type check when the project is typed, build, lint, tests, production audit) is found in the project whatever CI runs, budgeted to the sandbox's time, compared with the base branch, and recorded against the head; the settle stage cites the record, so "check not run" never stays open for a check of the set. Advisories are counted once: the base branch and the head read the same way and laid beside the package manager's audit, each disagreement with its cause, each remaining advisory with its package, whether the change touches it and why it stays. Each major carries its dependency paths, where they run, whether the repository uses it, the reachability verdict with its limit, and how it is fixed (a parent release that declares the fixed range before an override). A major the repository calls is probed through its call sites on the base branch's build and the head's; a changed answer is a known behaviour change, and a sentence that calls the contract or the behaviour unchanged without a probe that shows it is taken out. The record is of one commit, and a head that has moved since is said to have.
