# cu. `cu_chat_answers_the_question`

**What happened:** A person new to Chat asked what could be useful to someone in their role. Chat answered a different question. It led with the "what's waiting on you" list, one ticket's details first, because the prompt sent any "what should I work on" style question to that list and the list's lookup told the model to write every answer in its fixed shape. It also said Jira wasn't connected, a claim no check in that answer supported. The person's next message had to correct it, and Chat walked the claim back only in part. Separately, a question that linked a pull request comment got the canned "found nothing" line, because any answer that cited nothing was replaced by it, whatever the question.

**The guarantee:** Chat reads a question before it answers: what the person wants (an orientation, what Chat can do, what needs me, a status, a how-to, a lookup, a judgement, a correction of Chat itself, or small talk), the role they say they hold, and, for a correction, the sentences of the last answer they question. It answers that question first and sizes the answer to it. The "what needs me" list keeps its fixed shape only for that question; for any other, the lookup says to use only what answers it. An orientation looks the team's setup up (`coderhelm_setup`: each connection checked with the integrations page's own test, the runs and records counted) before it may answer. A correction must check the disputed point again in that answer, and a check that failed is named as that check, never as "not connected". An uncited reply is kept only for small talk; any other answer that cites nothing looks once with its tools before the plain no-source line replaces it.

**Where it's enforced:** `common::chat_intent::{read, Intent::fixed_shape, Intent::uncited_ok, Reading::note}`, `common::knowledge::answer::finalize_reply`; in the gateway, `chat_understand::{read, Understood::must_look, Understood::order}`, `chat_setup::{render, github_check, jira_check}`, `chat_work_needs::{render_for, NOT_THE_LIST}`, `chat_agent::cite_something`, `chat_hints` (pull request links), and the "Understand the question first" and "Check before you claim" parts of `brain::CHAT_SYSTEM`. The replay evals are `chat_eval_replay`.
