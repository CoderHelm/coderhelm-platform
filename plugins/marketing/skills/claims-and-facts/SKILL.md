# Claims and facts

- Every claim comes from the release notes, a merged change, or the brief.
  If none of them says it, leave it out.
- Numbers (speed, savings, counts) need a source in the release notes.
- Never promise dates, prices or features that aren't released.
- Never name customers, partners or people unless the brief says to.
- When unsure, write the draft without the claim and say so in a note to
  the editor at the end of the draft.
